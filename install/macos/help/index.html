Welcome to Project NOMAD

Your offline knowledge library & AI assistant

This Mac is now an island of knowledge. Wikipedia, an AI you can chat with, maps, books, reference guides — all on this machine, all without an internet connection. Here's what you can do with it.

What you have

Project NOMAD bundles several offline tools onto this Mac:

AI Assistant

Chat with a real AI like ChatGPT, but running on this Mac. Ask anything — survival questions, recipe ideas, code help, life advice. It works without internet.

Offline Wikipedia

Search Wikipedia like normal, but from local files. Includes the full encyclopedia plus topic-focused versions like medicine and the top 100 most-read articles.

Reference libraries

Stack Exchange Q&A on cooking, mechanics, gardening, woodworking, electronics, raspberry pi. Project Gutenberg books. iFixit repair guides. LibreTexts textbooks.

Education

Khan Academy, TED talks, freeCodeCamp, devdocs (Python, JavaScript, etc). Kolibri channels for structured learning.

Preparedness content

Canadian Prepper guides on bug-out concepts, food storage, winter prepping. Urban-prepper, FOSS cooking, military medicine references, NHS medicines reference.

Maps and notes

Offline maps you can browse zoomed in or out. A simple note-taking app for journaling, lists, or saving things you want to keep.

Workshop — 3D print library

An offline catalog of 3D-printable files (STL and 3MF). Drop files into folders on your data drive organized by category — medical, tools, household, replacement parts, agriculture — and they show up in the Command Center with thumbnails, material info, and print times. If something breaks and you have a printer, this is your parts bin.

Getting started

Most things you'll do happen through your web browser. Open Safari (or any browser) and visit either of these:

  • localhost:8080 — the main control panel ("Command Center"). This is your home base.
  • localhost:8090 — the library you're browsing right now (Kiwix). All the Wikipedia and reference content lives here.

Bookmark both. The Command Center is where you'll go to add new content, manage downloads, and chat with the AI. The library is where you go to read things.

Chatting with the AI

Open the Command Center (localhost:8080) and click on AI Assistant in the menu. You'll get a chat box. Type a question, hit send, get an answer.

Things to know about the AI:

  • It runs entirely on this Mac. Nothing you ask leaves the device.
  • It's fast on Apple Silicon Macs because it uses Metal (the Mac's graphics chip) for AI work.
  • It doesn't know about events after its training cutoff (early 2025 for the most current models). It can't look things up online — that's the trade-off for being offline.
  • You can pick which model to use. Smaller models are faster but less detailed. Bigger models are slower but more capable. The default is a good balance.
Try it Good first questions: "What can you help me with?" · "Explain how a sourdough starter works" · "Write a packing list for a 3-day camping trip with two kids" · "What are some signs of carbon monoxide poisoning?"

Browsing the library

The library at localhost:8090 is where all the offline reference content lives. Each "book" is a separate collection — Wikipedia, Project Gutenberg, a specific Stack Exchange site, a TED talks archive.

To search across everything, use the search bar at the top. To filter, use the dropdown on the left to narrow by language or category. Click any book to dive in.

If you don't see something you expect, try:

  • Clearing the category filter (it might be set to "Wikipedia" by default — change it to show all categories)
  • Waiting a moment if you've recently added new content — see When something looks off below

Using it from other devices

NOMAD is set up so other devices on your home WiFi can use it too — phones, tablets, laptops, anyone connected to the same network. They don't need their own copy. They just need a browser.

If you said "yes" to setting this Mac's network name during install, anyone on the same WiFi can simply visit:

  • http://nomad.local:8080 — Command Center
  • http://nomad.local:8090 — Library (this site)

That's the easy way. Type it into any browser on your phone, tablet, or another Mac on the same WiFi.

Use case Set this Mac up in your house, off-grid cabin, or RV. Family members type nomad.local:8080 into their browsers and have the same access. No internet needed for any of them.

If nomad.local doesn't work

Some networks (corporate WiFi, guest networks, certain mesh routers) block .local name resolution. In that case, find this Mac's IP address and use that instead.

Easiest way to find the IP — from System Settings on this Mac:

  1. Open System Settings (or System Preferences on older macOS)
  2. Click Wi-Fi in the sidebar
  3. Click Details next to your connected network
  4. Look for IP Address — it'll be something like 192.168.1.42

Then from any other device on the same WiFi, visit http://192.168.1.42:8080 (replace with the actual address you saw). Bookmark it once and you're set.

Want to change nomad.local to something else?

You can rename this Mac's network name any time:

  • System Settings → General → About → click "Local hostname" → type whatever you want (e.g. library, cabin, basecamp)
  • Or in Terminal: sudo scutil --set LocalHostName basecamp

After that, devices visit http://basecamp.local:8080. Whatever you pick.

Adding more content

The Command Center has a section called Content Manager (and another called Maps Manager). That's where you go to add more reference material — extra Wikipedia variants, additional Stack Exchange sites, more Khan Academy channels, regional offline maps.

When you queue something to download, NOMAD does it in the background. You can keep using everything else while downloads run. New content appears in the library within a minute or two of finishing.

Heads up Some downloads are huge. Full Wikipedia is about 95 GB. Downloads can take hours on a typical home connection. Plan ahead — start big downloads when you'll be near the Mac for a while.

Your privacy

Everything runs on this Mac. Specifically:

  • The AI Assistant runs locally. Your conversations never leave the device.
  • Wikipedia and other reference content is served from local files. Searches don't go to Google or anyone else.
  • No accounts, no logins, no usernames, no tracking.
  • Downloads (when you add new content) come from public archives like the Kiwix project — those connections are visible to your network, like any other download.

This means you can chat openly with the AI about whatever you want — health questions, financial planning, things you're embarrassed to type into a search engine. Nobody else sees it.

When something looks off

I just downloaded a book but the library doesn't show it.

Wait a minute — NOMAD checks for new content every 60 seconds. New books appear after the next check.

If it's been more than a few minutes and you still don't see it, open Terminal and type nomad fix-kiwix. That refreshes the library immediately.

The AI Assistant says no models are available.

The AI engine probably lost its connection to the models. Open Terminal and type nomad restart admin, wait 15 seconds, then refresh the page.

A book downloaded but it's broken or empty.

The download may have been interrupted. Open the Command Center, go to Content Manager, find the broken book, click Delete, then re-add it from the wizard. NOMAD will redownload it from scratch.

Everything seems slow or stuck.

Open Terminal and type nomad check. It scans the whole system and tells you what's wrong, in plain language, with a suggested fix for each issue.

My external drive came unplugged. What now?

The basics keep running — the AI's main systems are on the internal Mac drive. Plug the drive back in, then in Terminal type nomad up. Everything resumes where it left off.

I want to start completely fresh.

In Terminal, nomad reinstall. It'll ask once if you're sure (because this wipes content), then handle everything. Takes 15-30 minutes plus however long the new downloads take.

Something else is weird and I can't tell what.

You can always close everything, restart the Mac, and turn things back on with nomad up. NOMAD is designed to recover from interruptions cleanly.
