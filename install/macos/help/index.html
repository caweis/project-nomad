If the Command Center isn't responding

From Terminal, in roughly increasing severity:

First, see what's actually wrong

nomad check

This scans the whole stack and tells you what's broken in plain language, with the suggested fix for each issue.

Restart the admin interface

nomad restart admin

Wait 15–30 seconds, then refresh nomad.local. Most "page won't load" problems are solved here.

Restart everything cleanly

nomad down
nomad up

Stops every service and brings them all back up. Slower but more thorough than the targeted restart above.

The drive was unplugged — reconnect

Plug the drive back in, then:

nomad up

This re-runs the bring-up pass and reconnects services to the drive's content.

Reset just the AI Assistant

nomad reset-ollama

Use this if the AI is the only thing broken — your models stay, but the runtime gets a clean restart.

Nothing else works — full reinstall

nomad reinstall

Takes 15–30 minutes plus content download time. Your data on the drive is preserved; the application stack gets rebuilt.

Just want to chat with the AI right now

If you need the AI Assistant working immediately and don't want to wait for the full Command Center, your data drive includes a standalone chat surface that doesn't depend on the admin stack at all.

On the data drive, double-click:

quick-chat.sh

It starts a minimal Ollama daemon pointing at your downloaded models and opens a browser chat page. No Command Center, no Kiwix, no admin — just a clean chat against the models on your drive. See Your data drive for the full explanation.

When you're truly stuck

Last resorts

Restart the Mac, then nomad up. N.O.M.A.D. is designed to recover cleanly from interruptions.

If that doesn't fix it, run nomad check and read the output — most problems have a named cause and a named fix.

If you need to wipe and start over: nomad reinstall for the application stack, or run the installer fresh from the drive (install-nomad.command) to bring up a completely new install pointing at the same data drive.
